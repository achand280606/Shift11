# Shift11 – AI-Powered Football Momentum Attribution

### Detect the shift. Attribute the player. Explain why the game changed.

## Overview

Shift11 is an AI-powered football analytics system designed to identify meaningful momentum shifts during a football match, determine the players responsible for those changes, reconstruct the supporting event sequence, and generate grounded tactical explanations.

Instead of simply displaying football statistics, Shift11 focuses on explaining:

- **When did the game change?**
- **Who drove the change?**
- **What sequence caused it?**
- **Why did it matter tactically?**

## Core Principle

> **Deterministic analytics establish what happened; AI explains why it mattered.**

The AI does not determine match statistics or invent events. It receives verified analytical facts from the deterministic engine and converts them into understandable tactical explanations.

## Momentum Model

The demo momentum score uses five components:

| Component | Weight |
|---|---:|
| Territory / field position | 20% |
| Possession value / progression | 25% |
| Pressure & recoveries | 20% |
| Chance creation | 25% |
| Possession control | 10% |

Momentum is calculated using a **5-minute rolling window** and updated every **30 seconds**, with recent events receiving greater weight.

### Momentum Shift Detection

A momentum shift is detected when all of the following conditions are satisfied:

- Momentum increases by at least **15 points**
- Opponent momentum advantage increases by at least **10 points**
- The change persists for at least **60 seconds**
- At least **3 meaningful events** support the shift

Hysteresis/cooldown logic is used to reduce duplicate or noisy shift markers.

## Player Attribution & Evidence

For each detected momentum shift, Shift11 identifies:

1. Primary contributor
2. Secondary contributors
3. Contribution percentages
4. Tactical player roles
5. A coherent 5–7 event evidence chain
6. Before/after metrics

Example:

```text
Recovery
    ↓
Progressive Carry
    ↓
Line-breaking Pass
    ↓
Final-third Entry
    ↓
Shot
```

Possible player roles include:

- Momentum Catalyst
- Progression Driver
- Chance Creator
- Defensive Trigger
- Finisher

## Grounded AI

Shift11 uses a Microsoft-first AI architecture:

- **Microsoft Agent Framework** — agent and orchestration layer
- **Microsoft Foundry** — AI model/runtime and potential hosted-agent deployment
- **Azure** — deployment and supporting cloud services

The AI receives a structured **fact pack** generated by the deterministic analytics engine.

The AI is instructed to:

- Use only verified facts
- Never invent events
- Never invent statistics
- Explain tactical significance
- Reference the supporting evidence chain

## Development Philosophy

Shift11 separates **analysis from explanation**.

The deterministic system establishes the factual answer.

The AI system explains that answer.

This separation is designed to make the system:

- Reproducible
- Explainable
- Evidence-based
- Resistant to hallucinated match events
- Suitable for controlled synthetic-match testing
